# DSH Idea 使用指南

适用于本仓库当前 P2-Lite 界面。先确认 Web Profile 已加载插件；
入口总览和验证范围见 [README](../README.md)。以下中文名称对应当前中文界面。

## 保存一个 Idea

在普通对话的一条已完成回复下，点击灯泡 → **总结**。
选择「保存新 Idea」，再点「生成草稿」。选择保存方式本身不调用模型；
生成时显示准备状态，完成后在同一弹窗显示可编辑草稿。
检查标题、核心想法、为什么值得保留，以及可选的当前结论、可能价值、
适用场景和待解决问题，点「保存新 Idea」才会写入。

总结以所选回复为结束位置，包含该回复，最多取 12 条可见用户/助手文本、12,000 字符。
它不是整个会话的完整回忆，也不包含工具输出、插件注入的引用正文或更晚消息。
更新预览会显示消息范围及截断提示；长对话应先把关键结论写进可见讨论。

也可以从 **+ → Idea → ＋ 记录新想法**，或 **设置 → Ideas → ＋ 新建 Idea** 输入文字：

- 「直接保存」不调用模型，保留输入形成 Idea；之后可进详情编辑完整字段。
- 「AI 整理」调用模型形成可编辑预览，仍需明确保存；整理失败会保留原文。

准备期间可以取消或关闭；取消后的迟到结果不会重新打开预览。
保存一旦开始，关闭不能当作撤销已提交内容。失败提示和保留的草稿应先核对，
不要把关闭弹窗视为保存成功。

## 更新当前内容与版本演进

手动修改：**设置 → Ideas → 选择一条 Idea → 编辑 → 保存**。
无修改时不能保存；有未保存修改时，取消或返回详情会要求确认放弃。
适用场景和待解决问题可逐条添加、删除，也支持多行粘贴。

结合讨论更新：在相关回复下点灯泡 → **总结 → 更新已有 Idea**，
搜索并明确选中目标，核对「当前内容摘要」，再点「生成草稿」。
系统结合目标当前内容和本次有界对话拟稿；你可编辑预览，点「确认更新」才保存。
即使对话引用了其他 Idea，也只更新你选定的目标，系统不会自动推断归属。

一条 Idea 在库中只展示当前有效内容。更新会在底层保留旧记录；当前界面没有
版本历史、历史版本切换或回滚操作。AI 更新有变化时同时保存本次讨论来源；
普通手动编辑不新增讨论来源。内容无变化不会新增内容、来源或事件。

若其他操作已更新目标，会提示冲突并保留草稿，需要重新选择并主动生成，
不会自动套用到新基线。「保存结果未确认」时会读取当前内容供核对，
不会自动重写；临时预览票据也不能当作跨重启的永久草稿。

## 引用 Idea 与继续讨论

在普通对话输入框打开 **+ → Idea**，按标题或内容搜索，选择结果后点
「添加到对话」。引用先进入输入草稿，不会自动发送；写下讨论问题后由你发送。
新建普通对话也可以这样继续之前的想法。

引用固定在选择时的版本。之后 Idea 更新，已有引用不会自动变成最新内容；
需要新内容时重新从库选择。引用作为背景材料，不替代你的任务要求。
当前 UI 不再提供专用「讨论」或「演化提案」入口，也不显示「关联 Idea」对话卡片；
旧讨论会话仍可从 Harness 的正常会话入口打开。

## 查找相关 Idea

在一条回复下点灯泡 → **相关**，会打开标题为「关联 Idea」的结果窗口。
结果包含 Idea 摘要和「为什么现在有用」。可以「查看」，或「添加到对话」后再发送。
查询可能调用模型，也可能返回空结果或失败；打开和查看结果不会自动引用或保存。
这个查询窗口与已移除的旧关联对话卡片是不同入口。

## 情境提醒与主动找回

插件在符合条件的新对话轮次完成后判断是否需要找回 Idea。
存在候选且 Judge 认为能补充当前讨论时，输入区可能出现「Idea 提醒」。
打开历史会话、刷新或重连不会重放旧轮次；一次会话至多消费一次提醒展示预算，
忽略后不会退还。即使已有预算被消费后提醒因竞态失效，也不会补发。

你可以明确表达找回意图，例如「帮我找之前保存的 Idea」或
“Find the idea I saved earlier”。中文、英文和部分混合改写已有规则支持；
这是触发检索的机会，仍受轮次完成、候选、暂停偏好、Judge 和预算约束，
不保证一定找到或显示。「如何找回 Idea」等询问操作方法的表达与直接找回请求区分。
需要确定性查找时，使用 **+ → Idea** 或 Ideas 库的本地搜索。

提醒仅针对仍有效、未暂停的 active Idea。展示前及点击引用前会复核版本、状态和偏好；
已编辑、归档、删除或暂停的过时提醒不能继续引用旧内容，也不会静默换成新版本。

| 操作 | 效果 |
| --- | --- |
| 查看 | 展开只读内容，不添加到输入框。 |
| 引用 | 校验后把固定引用添加到输入草稿；仍由你发送。 |
| 本次忽略 | 关闭本次机会，不永久暂停，也不建立跨会话冷却。 |
| 暂停提醒 | 持久暂停这一条 Idea 的主动提醒，跨会话和重启保留；不是全局暂停。 |

发起暂停会立即作废此前尚未完成的引用操作。暂停失败会保留提醒条并显示
「暂停失败，请重试。」；迟到引用也不会自动执行，你仍可再次明确点击引用。
需要恢复时，到 **设置 → Ideas → 详情** 切换「提醒：已暂停 / 提醒：已开启」。
暂停不阻止手动搜索、引用或显式相关查询；通过明确找回意图触发的主动提醒仍受暂停约束。

## 管理与支持边界

Ideas 库提供「当前 / 已归档」、搜索和详情。归档会移出当前范围及主动提醒候选；
恢复后可继续编辑，原提醒暂停偏好仍保留。永久删除需要明确确认，不能恢复，
已有 Harness 对话不会随之删除。

已实现保存、当前内容更新、引用、显式相关查询和情境提醒；
自然语言找回和模型推荐是有限支持，没有通用语义理解或效果保证。
目前不提供自动保存、自动选择更新目标、用户版本管理、跨会话冷却或忽略偏好学习。
AI 整理、生成草稿及推荐链路依赖可用模型；手动保存、编辑和本地搜索不依赖模型。
